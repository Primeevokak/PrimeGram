Что внутри

Пять причин остаться

Ничего не нужно настраивать — всё работает сразу после установки.

01

Связь без плясок

Клиент сам разбирается, как достучаться до серверов. Без сторонних программ, без настроек и без ожидания при каждом запуске.

02

Файлы до 8 ГБ

Вместо двух, которые разрешает Telegram. У друга с PrimeGram это выглядит как обычный файл — ему делать ничего не нужно.

03

Голосовые в текст

Прямо на телефоне, без подписки и без интернета. Текст набегает по мере распознавания. Точность выбираете сами.

04

Лента каналов

Все непрочитанные посты подписок одним списком. Больше не нужно скакать по десяткам чатов, чтобы ничего не пропустить.

05

И десятки мелочей, которых не хватало

Встроенный браузер с блокировщиком рекламы. Поиск по числовому ID и номеру телефона. Временные подписки, которые отписывают сами. Настраиваемая боковая панель, свои переводчики, управление кэшем.

Для тех, кто пишет код

Плагины на Python

Один файл — и клиент делает то, что вам нужно. Совместимы с exteraGram: написанное под него обычно работает без правок.

  • Больше сорока библиотек уже внутри — от requests и pillow до pandas с matplotlib
  • Можно менять поведение самого клиента, а не только пользоваться готовыми крючками
  • Свои форматы файлов, свои схемы ссылок, свои экраны настроек
  • Документация с примерами, справочником и готовыми рецептами
__id__ = "hello"
__name__ = "Hello World"

from base_plugin import BasePlugin, HookResult, HookStrategy


class HelloPlugin(BasePlugin):

    def on_plugin_load(self):
        self.add_on_send_message_hook()

    def on_send_message_hook(self, account, params):
        if params.message == ".hello":
            params.message = "Привет из плагина 👋"
            return HookResult(strategy=HookStrategy.MODIFY)
        return HookResult()
