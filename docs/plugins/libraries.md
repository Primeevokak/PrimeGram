# Библиотеки

Тридцать девять пакетов вшиты в приложение: ставить не нужно, качать не нужно, работает без сети —
просто `import`. Ниже каждая с тем, зачем она в плагине и обо что об неё спотыкаются.

Версия с закреплением (`==`) указана там, где она закреплена намеренно —
[почему, написано внизу](#почему-версии-закреплены).

## Сеть

### `requests`
Синхронный HTTP, самый привычный способ сходить в чужой API.

```python
import requests
data = requests.get("https://api.example.com/v1/rate", timeout=10).json()
```

Задавайте `timeout` **всегда**. Без него запрос на мёртвый сервер висит до таймаута системы, и
если вы в хуке отправки — вместе с ним висит интерфейс.

### `httpx`
То же самое, но умеет и синхронно, и через `async`. Берите, если нужен HTTP/2 или пул соединений,
который живёт между вызовами.

### `aiohttp`
Асинхронный клиент и сервер. В плагине пригождается редко — своего цикла событий у вас нет, его
придётся заводить руками, — но если библиотека, которую вы используете, требует именно `aiohttp`,
он на месте.

### `brotli`
Распаковка одноимённого сжатия. Отдельно нужен нечасто: `requests` подхватывает его сам, когда
сервер отвечает `Content-Encoding: br`.

## Разбор данных

### `beautifulsoup4`
Разбор HTML. Терпит кривую разметку, которой в реальном вебе большинство.

```python
from bs4 import BeautifulSoup
soup = BeautifulSoup(html, "lxml")
title = soup.select_one("h1").get_text(strip=True)
```

Парсер указывайте явно — `"lxml"` быстрее встроенного в разы, и он у нас есть.

### `lxml`
Быстрый разбор XML и HTML на C, плюс XPath. Нужен сам по себе, когда данные приходят XML — RSS,
OPML, ответы старых API.

### `regex`
Замена встроенному `re` с поддержкой того, чего в нём нет: свойств Unicode, нечёткого поиска,
пересекающихся совпадений. Для текста на русском вперемешку с эмодзи разница заметна.

### `python-dateutil`
Разбор дат в любом человеческом виде и арифметика по календарю.

```python
from dateutil import parser, relativedelta
when = parser.parse("2026-08-01T21:00:00+03:00")
month_later = when + relativedelta.relativedelta(months=1)
```

### `packaging`
Сравнение версий по правилам PEP 440. Нужно, если плагин проверяет версию клиента или свою
собственную: наивное сравнение строк считает, что «1.10» меньше «1.9».

### `pyyaml`
YAML. Удобен для конфигураций плагина, которые человек будет править руками.

Читайте только через `yaml.safe_load` — обычный `load` умеет создавать произвольные объекты
Python из файла, и это ровно та дыра, о которой вы подумали.

## Изображения

### `pillow`
Всё про растровые картинки: открыть, изменить размер, обрезать, наложить, нарисовать текст,
сохранить.

```python
from PIL import Image, ImageDraw, ImageFont

image = Image.open(path).convert("RGB")
image.thumbnail((1280, 1280))
ImageDraw.Draw(image).text((24, 24), "PrimeGram", fill=(255, 255, 255))
image.save(out, quality=88)
```

Шрифт по умолчанию — растровый и крошечный. Для нормального текста берите `ImageFont.truetype`
с путём к системному шрифту, например `/system/fonts/Roboto-Regular.ttf`.

### `pyzbar`
Чтение QR-кодов и штрихкодов с изображения. Кодирует — не он; для генерации QR понадобится
`qrcode` через [свои пакеты](#свои-пакеты), он чистый Python.

```python
from pyzbar.pyzbar import decode
from PIL import Image

for code in decode(Image.open(path)):
    self.log(code.data.decode("utf-8"))
```

### `wordcloud` `==1.9.2`
Облако слов из текста. Требует `pillow` и `numpy`, оба на месте.

## Графики

### `matplotlib` `==3.6.0`
Единственный способ показать что-то посчитанное: чат принимает картинки, а не графики.

```python
import matplotlib
matplotlib.use("Agg")           # обязательно, до импорта pyplot
import matplotlib.pyplot as plt
```

Строка с `"Agg"` — не украшение. Без неё matplotlib ищет оконную систему, не находит и роняет
плагин. `Agg` рисует в память, что нам и нужно.

Между графиками зовите `plt.close()`. Забытые фигуры копятся в памяти, и десятый график в чате
случается уже на грани.

### `contourpy` `==1.0.5`, `kiwisolver` `==1.4.5`
Внутренности matplotlib: заливка изолиний и решатель ограничений для раскладки. Напрямую не
нужны, но без них он не соберётся, поэтому лежат рядом и с теми же закреплёнными версиями.

## Числа и таблицы

### `numpy`
Массивы и математика по ним. Половина остального списка стоит на нём.

### `pandas` `==2.1.3`
Таблицы, группировки, временные ряды. Для плагина, который собирает статистику по чату, это
разница между двадцатью строками и двумя.

```python
import pandas as pd
frame = pd.DataFrame(rows, columns=["дата", "автор", "символов"])
top = frame.groupby("автор")["символов"].sum().sort_values(ascending=False).head(10)
```

Импорт pandas стоит заметного времени и памяти. Если он нужен в одной редкой команде — импортируйте
внутри функции, а не наверху файла: плагин будет включаться быстрее.

### `pywavelets` `==1.4.1`
Вейвлет-преобразования. Узкая вещь: сжатие с потерями, шумоподавление, поиск особенностей в
сигнале.

### `editdistance` `==0.6.2`
Расстояние Левенштейна на C. Поиск с опечатками, угадывание команды, которую написали неточно,
сравнение похожих имён.

```python
import editdistance
if editdistance.eval(typed, ".статистика") <= 2:
    ...
```

### `bitarray` `==2.8.2`
Массив битов с операциями над ним. Для плотных множеств и фильтров Блума, когда `set` из
миллиона чисел уже неприлично много ест.

### `lru-dict` `==1.1.8`
Словарь с вытеснением давно не использованных на C. Готовый кэш фиксированного размера — берите
его вместо самодельного на `OrderedDict`.

### `cytoolz` `==0.12.2`
Функциональные помощники — `groupby`, `partition`, `merge_with`, ленивые цепочки. Реализация на C.

## Звук

### `miniaudio` `==1.59`
Декодирование и кодирование звука: mp3, ogg, flac, wav. Точка входа для плагина, который хочет
достать сэмплы голосового сообщения.

```python
import miniaudio
decoded = miniaudio.decode_file(path)
samples = decoded.samples            # array('h'), знаковые 16 бит
```

### `soxr` `==0.3.7`
Передискретизация высокого качества. Нужна, потому что модели и алгоритмы обычно ждут 16 кГц, а
голосовые Telegram приходят с другой частотой.

### `lameenc` `==1.7.0`
Кодирование в MP3. Закрывает круг: раскодировали, обработали, собрали обратно в файл, который
можно отправить.

## Криптография

### `cryptography`
Основной набор: AES, RSA, ECDSA, X.509, Fernet. Если сомневаетесь, что брать, — берите это.

### `pycryptodome`
Продолжение старого PyCrypto. Нужен, когда чужой код импортирует `Crypto.Cipher` и переписывать
его вы не собираетесь.

### `pynacl`
Обёртка над libsodium: Ed25519, X25519, XSalsa20-Poly1305. Современные примитивы, которые трудно
использовать неправильно.

### `bcrypt`
Хеширование паролей. Медленный намеренно — в этом весь смысл.

### `argon2-cffi` `==20.1.0`
Хеширование паролей, победитель конкурса PHC. Устойчивее bcrypt к перебору на видеокартах.

### `tgcrypto`
Ускоренная реализация шифров MTProto. Здесь потому, что плагины, портированные из мира Pyrogram,
её ожидают.

## Сжатие

### `zstandard`
Zstd — лучшее соотношение скорости и степени сжатия из доступного. Для собственных архивов
плагина берите его.

### `lz4`
Когда важна только скорость: распаковка идёт со скоростью памяти. Хорош для кэшей, которые
переживают перезапуск.

## Система и прочее

### `psutil`
Память, процессор, диск, процессы. В плагине — чтобы показать, сколько приложение занимает, или
не начинать тяжёлую работу на телефоне, которому и так плохо.

### `netifaces` `==0.10.9`
Список сетевых интерфейсов и их адресов.

### `ephem` `==3.7.7.0`
Астрономия: фазы луны, восходы и закаты, положения планет на дату. В списке потому, что плагины
с гороскопами и напоминаниями «через час стемнеет» пишут чаще, чем можно предположить.

### `markupsafe` `==3.0.3`, `greenlet` `==3.0.1`
Сами по себе не нужны почти никому. Лежат тут, чтобы работали большие **чистые** библиотеки,
которые плагин может доставить сам: `jinja2` требует markupsafe, асинхронный режим `sqlalchemy` —
greenlet. Обе половинки компилируемые, поэтому вшиты заранее — иначе установка через
`__requirements__` упиралась бы в них.

## Свои пакеты

Чего нет внутри, плагин доставляет с PyPI:

```python
__requirements__ = ["emoji", "humanize>=4.0", "qrcode"]
```

Скачивается при установке плагина, кладётся в каталог плагинов, само приложение не трогает. Список
установленного и кнопка «очистить» — в разделе плагинов в настройках.

**Только чистый Python.** Пакет, которому нужна компиляция, так поставить нельзя: компилятора на
телефоне нет. Как отличить заранее: если на PyPI у пакета есть файл `...-py3-none-any.whl` —
поставится. Если только `...-cp311-...-android_....whl` или `.tar.gz` — нет.

Зависимости подтягиваются рекурсивно. Если плагин импортирует то, чего не объявил, загрузчик
попробует достать это один раз по имени модуля — часто помогает, но полагаться на это не стоит.

## Чего нет

`scipy` · `opencv-python` · `ujson` · `soundfile` · `coincurve` · `ta-lib` · `shapely` ·
`marisa-trie` · `tflite-runtime`

Причина общая: сборок под Android для Python 3.11 не существует — они останавливаются на 3.10 или
3.8. Собирать их самим означало бы вести собственный форк каждой, а уходить на старый Python —
ломать совместимость с плагинами exteraGram, которые пишут под 3.11.

Замены, которые обычно закрывают вопрос:

| Хотелось | Берите |
|---|---|
| `opencv` ради обработки картинок | `pillow` + `numpy` |
| `opencv` ради чтения QR | `pyzbar` |
| `ujson`, `orjson` | встроенный `json`, он давно быстрый |
| `soundfile` | `miniaudio` |
| `scipy.signal` ради ресемплинга | `soxr` |
| `scipy` ради статистики | `numpy` и `pandas` |

## Почему версии закреплены

Chaquopy собирает пакеты под Android сам и держит их в своём репозитории. Когда его сборка
отстаёт от последнего релиза на PyPI, незакреплённый запрос уходит к **исходникам** на PyPI, и pip
пытается скомпилировать нативное расширение на машине сборки. На Windows это падает, на Linux —
собирается под неё же и не работает на телефоне.

Поэтому каждый пакет, чья сборка под Android перестала обновляться, закреплён на последней версии,
которая для Python 3.11 существует. Проверить конкретный можно так: откройте
`https://chaquo.com/pypi-13.1/<имя>/` и поищите файл с тегом `cp311`.
